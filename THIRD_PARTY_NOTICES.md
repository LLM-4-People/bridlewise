## Vendored or generated material

The public product snapshot does **not** include the private verification corpus, the internal traceability evidence, or the vendored Git source that the private repository used for path-policy verification.

The PWA icons in `public/icons/` are original Bridlewise assets generated by `scripts/generate-pwa-icons.mjs`.

## Fonts

The cockpit requests IBM Plex Sans and IBM Plex Mono. The public repository does not vendor font binaries. If the fonts are not installed locally, the browser falls back to the platform UI font. IBM Plex is licensed under the SIL Open Font License 1.1; if you bundle it, include the OFL notice.

## Testing repository

The separate `bridlewise-testing` repository includes Unicode normalization data and protocol/spec excerpts used for verification. Those files retain their upstream licenses; see that repository's `THIRD_PARTY_NOTICES.md`.
