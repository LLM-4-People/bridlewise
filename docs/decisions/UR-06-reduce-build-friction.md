# Every round's friction becomes tooling

After every writer round a friction reviewer turns the round's pain points
into concrete repo-native tooling or workflow changes; accepted items become
writer tasks; each lesson is one file in `docs/trackers/workflow-lessons/`
with its status and where it was acted on. Every improvement lives in this
repository and stays generic enough for any agent or harness to use.
