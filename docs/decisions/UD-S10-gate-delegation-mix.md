# Each gate's mixed run delegates 25% of turns, three wide, two deep

The default delegation mix of every gate's `mixed` run: 25% of turns
delegate, 3 concurrent sub-agents, depth at most 2 — a setting
([UR-05](UR-05-expose-settings-signals-actions.md)); the `fanout` mix
stresses wider trees separately
([SCALE-AGENTS](SCALE-AGENTS-capacity-counts-every-agent.md)).
