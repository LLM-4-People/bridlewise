# Coordinate through delegated agents

"ALWAYS delegate to agents, you are a coordinator" (user, 2026-10-04). The
primary agent plans, briefs and dispatches; it does not itself do work a
delegated agent can do, so no one context is overwhelmed. Substantive
discovery, research, implementation and review are delegated; the coordinator
keeps the queue, the decisions and the handoffs, and each completed step hands
off the next ([UR-14](UR-14-continuation-mandate.md)).

The operational home is [ROLES.md](../process/ROLES.md) with the dispatch
rules of [AGENTS.md](../process/AGENTS.md); the concurrency bound is
[UR-10](UR-10-one-writer-per-repository.md) (one writer at a time, readers as
many as the machine carries) and delegated research follows
[UR-11](UR-11-research-when-not-certain.md).
