# Caching never sacrifices a harness function

A prompt-cache gain never removes or degrades a harness function (dynamic
tools and breakers, workspace awareness, memory recall, summaries, the repo
map, notices, trimming) without a written pros/cons analysis and the user's
approval. The default is a layout that keeps both the function and the
cache (volatile content moves to the tail instead of being dropped).
