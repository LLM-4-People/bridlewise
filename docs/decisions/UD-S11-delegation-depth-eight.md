# Delegation depth defaults to 8

The maximum delegation depth (`agents.admission.maxDepth`) defaults to 8 and
is configurable ([UR-05](UR-05-expose-settings-signals-actions.md)); it is
the one remaining refusal for sub-agents, answered as a recoverable tool
result ([SCALE-AGENTS](SCALE-AGENTS-capacity-counts-every-agent.md)).
