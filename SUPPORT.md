# Support

Bridlewise is a **developer preview**. There is no commercial support, no SLA, and no guarantee that a question will be answered.

## Where to ask

- **Questions and ideas:** GitHub Discussions (enable it on the repository if it is not already on).
- **Reproducible bugs:** GitHub Issues using the bug report template.
- **Security reports:** follow [SECURITY.md](SECURITY.md). Do not open a public issue with exploit details.

## Before opening an issue

1. Confirm you are on the latest `main`.
2. Read [docs/quickstart.md](docs/quickstart.md) and the troubleshooting section.
3. Search existing issues and discussions.
4. Reduce the report to one reproducible behavior.
5. Include your OS, Node version (`node -v`), npm version, and the exact commands you ran.
6. Remove secrets, absolute home paths, private repository names, and personal data from logs.

## What is out of scope

- Production deployment support.
- Security guarantees for sensitive codebases.
- Model-provider billing, outages, or account issues.
- Requests to make the project production-ready on a deadline.
- Support for non-Linux hosts beyond documented WSL caveats.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md). The development floor, including the test and verification suites, lives in the separate [`bridlewise-testing`](https://github.com/LLM-4-People/bridlewise-testing) repository.
